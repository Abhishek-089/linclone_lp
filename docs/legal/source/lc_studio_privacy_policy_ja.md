# LC Studio プライバシーポリシー（クリエイター向け）

LinClone株式会社（以下「当社」）は、クリエイター向けアプリケーション「LC Studio」及びAIクローンの公開に関するサービス（以下「本サービス」）において、クリエイター、本人及び所属事務所等の担当者の個人情報を、個人情報の保護に関する法律（以下「個人情報保護法」）、行政手続における特定の個人を識別するための番号の利用等に関する法律（以下「番号法」）その他の法令に従い、以下のとおり取り扱います。本ポリシーで使用する用語は、LC Studio利用規約（クリエイター向け）（以下「クリエイター規約」）の定義に従います。

フォロワーの個人情報の取扱いは、ファンアプリのプライバシーポリシーに定めます。

## 第2条（取得する情報）

当社は、次の情報を取得します。

1. 登録情報：Googleアカウント又はApple IDの連携により受け取るメールアドレス、氏名（提供される場合）、アカウント識別子。所属事務所又は法人が登録する場合は、その名称、担当者の氏名及び連絡先
2. 本人の素材：声（音声ファイル及びAIインタビューの録音）、写真・映像、氏名・芸名、プロフィール
3. AIクローンの設定：ペルソナ、NGトピック、関係性モード、公開範囲、SNS投稿・公認切り抜きの許可、新しい機能への同意の有無
4. 同意・確認の記録：本人の生年月日又は年齢区分、本人の同意及び保護者の同意の確認（チェック欄）とその日時、招待コード
5. 本人確認に関する情報：公式SNSアカウント、確認のためのやり取りの内容、声の持ち主の確認のために本人が画面の文章を読み上げた録音
6. 報酬・支払いに関する情報：報酬の計算、報酬残高及び出金の記録、受取先の情報（金融機関の口座、送金サービスのアカウント等）、居住国、クローン作成料の購入記録（アプリストアの取引識別子を含みます）。クレジットカード番号等の決済情報はアプリストアが取得し、当社は取得しません。
7. 税務に関する情報：適格請求書発行事業者の登録の有無及び登録番号、支払明細（仕入明細書）とその確認の記録、並びにマイナンバー（個人番号）その他税務手続に必要な情報（マイナンバー等は当社が提出を求めた場合に限ります）
8. 端末・ログ情報：端末の種類、OS、アプリのバージョン、IPアドレス、プッシュ通知用のトークン、不具合の発生状況、LC Studioの利用ログ（フォロワー情報の閲覧の記録を含みます）
9. お問い合わせ、通報及び権利侵害の申立ての内容

## 第3条（利用目的）

当社は、取得した情報を次の目的で利用します。

1. LC Studioの提供及びアカウントの管理
2. クリエイター規約第8条の範囲での、AIクローン及び声のモデルの作成・運用、並びにファンアプリでの公開
3. 申請の審査、本人確認、なりすまし・不正の防止
4. 報酬の計算・支払い及びクローン作成料の管理
5. 源泉徴収、支払調書等の法定調書の作成・提出、仕入明細書の作成その他の税務手続
6. クリエイター規約第17条に定める本サービスの宣伝
7. お知らせ、プッシュ通知その他の連絡
8. お問い合わせへの対応、トラブルの調査、通報・権利侵害の申立てへの対応、法令に基づく対応
9. 素材やAIクローンの設定が禁止事項に該当しないかの確認（AIによる自動判定を含みます）
10. 個人を特定できない統計情報への加工、及び本サービスの改善・新機能の開発（声の素材、AIインタビューの録音及び声のモデルを除きます）
11. 本サービスに関するお知らせ、キャンペーンその他のメール配信

マイナンバーは、第5号のうち法定調書の作成・提出のためにのみ利用します。第11号のメールは、登録時に受け取ることに同意した方に限り送ります。各メールに記載するリンクから、いつでも配信を停止できます。配信を停止しても、規約の変更や報酬の支払いなど、本サービスの利用に必要なお知らせは引き続き送ります。

## 第4条（声のデータの取扱い）

1. 当社は、本人の声の素材及び声のモデルを、クリエイター規約第8条の範囲でのみ利用します。クリエイターの許諾なく、他のサービスや第三者に転用、提供又は販売せず、当該AIクローン以外のAIモデルの学習にも利用しません。
2. AIインタビューの録音は、声のモデルの作成及びAIクローンのペルソナ（プロフィール）の作成に利用し、それ以外には利用しません。声の持ち主の確認のための読み上げの録音は、その確認にのみ利用します。
3. 声のモデルの作成及び音声の合成を外部の事業者に委託する場合、当社は、委託先が声の素材及び声のモデルを委託先自身のAIモデルの学習に利用しない設定及び契約条件のもとで委託します。声のモデルを委託先の他の利用者に公開・提供することもありません。
4. 声のモデルを新しい機能で利用する場合は、クリエイター規約第9条に従い、本ポリシーを改定したうえで、機能ごとにクリエイターの同意を得ます。同意はいつでも撤回できます。
5. 声の素材及び声のモデルにアクセスできる担当者は当社が権限を与えた者に限り、アクセスの記録を残します。
6. 声の素材及び声のモデルは、契約の終了から30日以内に、当社及び委託先から削除します（第10条）。

## 第5条（公開される情報）

1. 次の情報は、AIクローンのプロフィールとしてファンアプリで公開されます。公開範囲を限定URLに設定した場合は、そのURLを知る方に公開されます。
    1. 氏名・芸名、ユーザー名、プロフィール写真及びプロフィール
    2. AIクローンの発話及び音声
    3. LIVE配信の映像・音声
2. 前項の情報は、クリエイター規約第17条に従い、アプリストアの紹介画像、広告、当社の公式SNS及び公式切り抜きでも利用することがあります。
3. メールアドレス、所属事務所等の担当者の連絡先、受取先の情報、税務に関する情報及び本人確認に関する情報は、フォロワーに公開しません。

## 第6条（第三者提供）

1. 当社は、次の場合を除き、個人データを第三者に提供しません。
    1. 本人の同意がある場合
    2. 法令に基づく場合（税務署への法定調書の提出、裁判所の命令、捜査機関からの照会、弁護士会からの照会等）
    3. 人の生命、身体又は財産の保護のために必要で、本人の同意を得ることが困難な場合
    4. 合併、事業譲渡その他の事由による事業の承継に伴う場合
2. クリエイターは、登録時に、次の提供に同意するものとします。
    1. 報酬の支払いのため、受取先の金融機関又は送金サービス事業者に、受取人の氏名・名称、受取先の情報及び支払額を提供すること
    2. 本人又はその代理人から、AIクローンの作成・公開への同意の有無について問合せを受けた場合に、問合せをした方が本人又はその代理人であることを確認したうえで、登録者の氏名又は名称及び登録日を本人に伝えること
3. 権利侵害の申立てに関する紛争への対応のため、当社が依頼する弁護士に必要な情報を提供することがあります。
4. マイナンバーは、前各項にかかわらず、番号法第19条に定める場合を除き、第三者に提供しません。

- クラウドサーバーでのデータの保管

## 第8条（外国にある第三者への提供等）

1. 当社は、本サービスのデータを、アマゾン ウェブ サービス ジャパン合同会社が提供するクラウドサービス（Amazon Web Services。以下「AWS」）に保存します。声のモデルの作成及び音声の合成、並びにAIクローンの応答の生成及び音声の認識は、外部のAI事業者に委託して処理します。

| 取扱い | 事業者の所在国 | データを処理・保存する国 |
| --- | --- | --- |
| データの保存（AWS） | 日本（親会社は米国のAmazon Web Services, Inc.） | 日本（東京リージョン） |
| 声のモデルの作成、音声の合成 | 米国 | 米国（処理の一部はオランダ又はシンガポールで行われることがあります） |
| AIクローンの応答の生成、音声の認識 | 米国等 | 米国等 |

2. AWSへの保存は、AWSが保存データの内容を取り扱わない契約条件のもとで利用し、当社自身の安全管理措置（第11条）として管理します。
3. AIによる処理は、委託先との契約により、個人情報保護法に定める措置に相当する措置を継続的に講じる体制を整えたうえで行います。当社は、委託先による措置の実施状況を定期的に確認し、クリエイター及び本人の求めに応じて、当該措置に関する情報を提供します。
4. 報酬の受取先として外国の金融機関又は送金サービスを選択した場合、その事業者の名称、所在国及び当該国の個人情報保護制度をLC Studioの受取方法の選択画面に表示し、同意を得たうえで提供します。
5. 米国には、日本の個人情報保護法に相当する包括的な連邦法はなく、州法や分野ごとの法律で個人情報が保護されています。オランダにはEUの一般データ保護規則（GDPR）が、シンガポールには個人データ保護法（PDPA）が適用されます。各国の制度は、個人情報保護委員会の「外国における個人情報の保護に関する制度等の調査」で確認できます。
6. マイナンバーは、外国にある第三者に提供しません。

## 第10条（保存期間）

1. 声の素材、声のモデル、その他の素材、並びにペルソナその他のAIクローンの設定は、契約の終了から30日以内に、当社及び委託先から削除します。委託先のバックアップに残る複製は、委託先の定めにより、その後30日以内に消去されます。ただし、法令に基づく場合及び紛争への対応に必要な記録は、その対応に必要な期間保存します。
2. 登録情報、同意・確認の記録、本人確認に関する情報及びフォロワー情報の閲覧の記録は、契約の終了後1年間保存したうえで削除します。保存中は、トラブルの調査及び法令への対応のためにのみ利用します。
3. 報酬、支払い及びクローン作成料の記録は、法令が定める期間保存します。
4. マイナンバーは、番号法に基づき、税務手続に必要な期間が経過した後、速やかに削除・廃棄します。
5. AIクローンとフォロワーとのやり取り履歴（音声の合成の委託先に残る生成の履歴を含みます）は、ファンアプリのプライバシーポリシーに従い取り扱います。
6. 委託先に預けたデータも、本条の期間に従い削除します。

## 第11条（安全管理措置）

当社は、個人データの漏えい等を防ぐため、次の措置を講じています。

1. 基本方針の策定：本ポリシーを定め、公表しています。
2. 規律の整備：取得、利用、保存、提供、削除の各段階の取扱いを社内規程で定めています。
3. 組織的措置：個人情報保護管理者を置き、漏えい等の事故の報告体制を整えています。
4. 人的措置：従業員及び業務委託先に守秘義務を課し、定期的に教育を行います。
5. 物理的措置：個人データを扱う端末の盗難・紛失を防ぐ措置を講じています。
6. 技術的措置：アクセス権限の管理、通信及び保存データの暗号化、閲覧の記録、不正アクセスの監視を行います。声の素材、声のモデル、受取先の情報及び税務に関する情報は、閲覧できる担当者を特に限定します。
7. マイナンバーの管理：番号法に基づき、取扱担当者を限定し、他の情報と区分して管理します。
8. 外的環境の把握：個人データを取り扱う外国（米国、オランダ、シンガポール等）の個人情報保護制度を把握したうえで、第8条の措置を講じています。
