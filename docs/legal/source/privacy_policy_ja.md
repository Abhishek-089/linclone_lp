# LinClone プライバシーポリシー

LinClone株式会社（以下「当社」）は、アプリケーション「LinClone」及びこれに関連するサービス（以下「本サービス」）における利用者の個人情報を、個人情報の保護に関する法律（以下「個人情報保護法」）、電気通信事業法その他の法令に従い、以下のとおり取り扱います。本ポリシーで使用する用語は、本サービスの利用規約の定義に従います。

- 住所：〒113-0032 東京都文京区弥生2-5-10 創志荘402
- 代表者：白石憲正

## 第2条（取得する情報）

当社は、次の情報を取得します。

1. 登録情報：Googleアカウント又はApple IDの連携により受け取るメールアドレス、氏名（提供される場合）、アカウント識別子。Apple IDでメールアドレスを非公開にした場合は、Appleが発行する中継用アドレスを受け取ります。
2. プロフィール情報：表示名、ユーザー名、プロフィール画像、生年月日又は年齢区分、言語設定、保護者の同意の記録（18歳未満の方）
3. やり取り履歴：AIクローンとのチャット（テキスト、ボイスメッセージ、画像）、通話の日時・時間及び会話の文字起こし、LIVE配信でのコメント・ギフト・視聴の記録、ストーリー及びそれへの反応、育成への投稿、関係性・呼び方・記憶の設定
4. 購入情報：購入日時、商品、金額、アプリストアの取引識別子、コインの付与・消費・失効の記録。クレジットカード番号等の決済情報はアプリストアが取得し、当社は取得しません。
5. 端末・ログ情報：端末の種類、OS、アプリのバージョン、IPアドレス、プッシュ通知用のトークン、不具合の発生状況、本サービスの利用ログ
6. お問い合わせ、通報及び権利侵害の申立ての内容

## 第3条（利用目的）

当社は、取得した情報を次の目的で利用します。

1. 本サービスの提供（アカウント管理、AIクローンとのチャット・通話・LIVEの提供、会話の文脈を保つ記憶機能）
2. 第5条に定めるクリエイターへの提供
3. コインパス・コイン・サブスクリプションの管理、購入の確認、不正な購入の防止
4. 年齢に応じた機能制限（有料の関係性モードの18歳以上制限、未成年の方の購入上限を含みます）
5. ユーザー間又はユーザーとクリエイター間のトラブルの調査、本人の求めへの対応、障害の調査、通報・権利侵害の申立てへの対応、法令に基づく対応
6. お知らせ、プッシュ通知、コインの失効予告その他の連絡
7. お問い合わせへの対応
8. 第4条に定める統計・内部分析、及び本サービスの改善・新機能の開発
9. キャンペーン、新機能その他のお知らせのメール配信

第9号のメールは、登録時に受け取ることに同意した方に限り、登録メールアドレスに送ります。各メールに記載するリンクから、いつでも配信を停止できます。配信を停止しても、規約の変更や購入の確認など、本サービスの利用に必要なお知らせは引き続き送ります。

## 第4条（統計・内部分析）

1. 当社は、取得した情報を、個人を特定できない統計情報に加工し、本サービスの改善や事業上の分析に利用します。
2. 当社が外部に開示するのは、個人を特定できない統計情報に限ります。

## 第5条（クリエイターへの提供）

1. 当社は、ユーザーの同意に基づき、ユーザーがフォローするAIクローンのクリエイターに対し、次の情報を提供します。
    1. 表示名、ユーザー名、プロフィール画像
    2. フォローの開始日及び状況
    3. 当該AIクローンとのチャットの内容
    4. 当該AIクローンとの通話の日時・時間及び会話の文字起こし
    5. 当該クリエイターのLIVE配信でのコメント、ギフト及び視聴の記録
    6. 当該AIクローンに対する関係性・呼び方・記憶の設定及び育成への投稿
    7. 上記に関するコインの消費状況
2. クリエイターは、フォロワーとの交流を目的として、前項の情報（チャットの内容及び通話の文字起こしを含みます）をいつでも閲覧できます。
3. 提供の方法：クリエイター向けアプリ（LC Studio）上での閲覧
4. 提供先：フォロー中のAIクローンのクリエイター。クリエイターの所属事務所等がアカウントを共同で管理している場合は、当該事務所等の担当者を含みます。
5. 当社は、メールアドレス、氏名その他の連絡先及び決済情報をクリエイターに提供しません。
6. フォローを解除すると、以後の提供は停止します。

## 第6条（当社によるやり取り履歴の確認）

1. 当社の担当者が通常確認できるのは、やり取りの日時・時間・種類等の記録（ログ）に限ります。
2. チャットの内容や通話の文字起こしは、トラブルの調査、本人の求め、障害の調査の場合に限り、必要な範囲で確認します（利用規約第9条）。裁判所の令状その他法令に基づく場合は、法令に従います。
3. 閲覧できる担当者は当社が権限を与えた者に限り、閲覧の日時・担当者・対象を記録します。
4. 確認した内容は、トラブルの解決、本人への回答、障害の解消及び法令への対応のためにのみ利用します。必要に応じて当社が依頼する弁護士、裁判所その他の公的機関に提出しますが、紛争の相手方を含むそれ以外の第三者には開示しません。

## 第7条（その他の第三者提供）

当社は、第5条のほか、次の場合を除き、個人データを第三者に提供しません。

1. 本人の同意がある場合
2. 法令に基づく場合（裁判所の命令、捜査機関からの照会、弁護士会からの照会等）
3. 人の生命、身体又は財産の保護のために必要で、本人の同意を得ることが困難な場合
4. 合併、事業譲渡その他の事由による事業の承継に伴う場合

## 第8条（業務の委託）

当社は、利用目的の達成に必要な範囲で、次の業務を外部に委託し、個人データを預けることがあります。委託先とは契約を結び、適切に監督します。

- クラウドサーバーでのデータの保管
- AIクローンの応答の生成、音声の合成・認識
- プッシュ通知の配信、メール配信
- アプリの不具合の分析
- 本サービスの開発・保守
- お問い合わせ対応

## 第9条（外国にある第三者への提供等）

1. 当社は、本サービスのデータを、アマゾン ウェブ サービス ジャパン合同会社が提供するクラウドサービス（Amazon Web Services。以下「AWS」）に保存します。AIクローンの応答の生成及び音声の合成・認識は、外部のAI事業者に委託して処理します。

| 取扱い | 事業者の所在国 | データを処理・保存する国 |
| --- | --- | --- |
| データの保存（AWS） | 日本（親会社は米国のAmazon Web Services, Inc.） | 日本（東京リージョン） |
| AIクローンの応答の生成、音声の合成・認識 | 米国等 | 米国等 |

2. AWSへの保存は、AWSが保存データの内容を取り扱わない契約条件のもとで利用し、当社自身の安全管理措置（第12条）として管理します。
3. AIによる処理は、外国にある第三者への委託として、委託先との契約により個人情報保護法の趣旨に沿った措置を講じさせるとともに、登録時の同意画面で同意を得て行います。
4. 米国には、日本の個人情報保護法に相当する包括的な連邦法はなく、州法や分野ごとの法律で個人情報が保護されています。各国の制度は、個人情報保護委員会の「外国における個人情報の保護に関する制度等の調査」で確認できます。

## 第10条（外部送信）

現在、本サービスには、利用状況の分析や広告のために、ユーザーの端末から外部の事業者へ情報を送信するツールを組み込んでいません。今後導入する場合は、事前に本ポリシーを改定し、送信される情報、送信先及び利用目的を公表します。

## 第11条（保存期間）

1. やり取り履歴は、アカウントが存続する間保存し、退会後は1年間保存したうえで削除します。退会後の保存中は、トラブルの調査及び法令への対応のためにのみ利用します。
2. 購入の記録は、法令が定める期間保存します。
3. やり取り履歴の閲覧の記録は、対象のやり取り履歴を削除するまで保存します。

## 第12条（安全管理措置）

当社は、個人データの漏えい等を防ぐため、次の措置を講じています。

1. 基本方針の策定：本ポリシーを定め、公表しています。
2. 規律の整備：取得、利用、保存、提供、削除の各段階の取扱いを社内規程で定めています。
3. 組織的措置：個人情報保護管理者を置き、漏えい等の事故の報告体制を整えています。
4. 人的措置：従業員及び業務委託先に守秘義務を課し、定期的に教育を行います。
5. 物理的措置：個人データを扱う端末の盗難・紛失を防ぐ措置を講じています。
6. 技術的措置：アクセス権限の管理、通信及び保存データの暗号化、閲覧の記録、不正アクセスの監視を行います。
7. 外的環境の把握：個人データを取り扱う外国（米国）の個人情報保護制度を把握したうえで、第9条の措置を講じています。

## 第13条（開示等の請求）

1. ユーザーは、当社に対し、保有個人データの利用目的の通知、開示（電磁的記録による開示を含みます）、訂正・追加・削除、利用停止・消去、第三者提供の停止及び第三者提供の記録の開示を請求できます。
2. 請求は第17条の窓口で受け付けます。当社は、本人確認のうえ、法令に従い遅滞なく対応します。

## 第14条（未成年者）

1. 本サービスは年齢を問わず利用できますが、未成年の方は法定代理人の同意を得たうえで利用してください。
2. 18歳未満の方の登録時は、保護者（法定代理人）の同意をチェック欄で確認し、その日時を記録します。16歳未満の方の個人情報は、保護者の同意を得て取り扱い、保護者は当社に対し、当該個人情報の利用停止・消去を請求できます。

## 第15条（AIによる自動処理）

1. 当社は、投稿等やAIクローンの発話に禁止事項に該当する内容が含まれていないかを、AIで自動的に判定することがあります。判定の結果、保存や表示を制限することがあります。
2. 当社は、やり取り履歴を、当該AIクローンとの会話の文脈を保つために利用し、それ以外のAIモデルの学習には利用しません。

## 第16条（改定）

当社は、法令の改正やサービスの変更に応じて本ポリシーを改定します。重要な改定は、効力発生日の前に本サービス上で通知します。第5条又は第6条の範囲を広げる改定は、改めて同意を得て行います。
